# 爆款视频逐镜拆解库

Video Breakdown Cases — a shot-by-shot breakdown library of viral short videos, by a working director/cinematographer.

把热门短视频一镜一镜拆开：切点在哪、景别怎么配、节奏怎么堆、镜头语言为什么成立，再给出能直接拿去复刻的提示词方向。拆解者是实拍导演/摄影师，拆的是自己做 AI 短剧时真在用的东西，不是自动工具跑出来的流水账。

## 拆解标准

每个案例尽量包含五块：

1. **基本信息**：片源、时长、数据、制作方式（能查到的都注明来源）
2. **逐镜表**：每个切点的时间、景别、时长
3. **节奏数据**：总镜数、平均镜长、加速段落在哪
4. **可复用的规律**：换个题材也能用的结构和镜头规则
5. **复刻提示词方向**：想用 AI 生成同类镜头时，提示词该怎么写

# 003 汪汪喵爸《围猎》：AI 写实短片的对峙镜头怎么拍

- 片源：抖音「汪汪喵爸」第 10 集《围猎》，视频 ID 7686044906028092710
- 时长：3:01，横屏 16:9
- 制作方式：作者声明全片 AI 生成（文生视频，无真人肖像和声音）
- 拆解方法：完整观看 3 遍后整理（观看环境无法外放声音，音乐与环境声未确认）

## 可借鉴的镜头语言

- **两狗对话近景**：平视，狗脸占画面主体，浅景深，背景虚化。对话戏不用全景铺陈，直接近景贴脸。
- **冷暖对比**：暖火光、暖金日光对冷蓝夜色与阴影，一场戏里的两个阵营先用色温分开。
- **三方对峙特写**：侧面平视，狗在左、狼在右同框，鼻尖相对，用固定长镜头靠「不切」制造紧张——不靠剪辑加速，靠时长压人。
- **低角度仰拍狼**：机位一低，狼显得比狗大一圈，体型压迫感不用特效。
- **情绪靠眼神不靠大动作**：惊觉和警戒用眼睛特写加长时间凝视表达，动作幅度反而收着，写实感就是这么来的。
- **数量一致**：全片狼始终明确为 3 只，同框不超过 3 只，靠排成一线建立数量感。AI 生成最容易在数量上穿帮，先把同框数量压住。
- **字幕样式**：白色字幕居中偏下、带黑边，内嵌画面。

## 结构参考

- **冷开场**：先给结局式对峙特写，再闪回交代来路。
- **威胁出现三级递进**：航拍远景排成一线 → 低角度正面迎镜头 → 侧面跟拍贴身。同一拨威胁，三种景别逐级逼近。
- **剪辑节奏电影式慢**：平均每镜 10–13 秒，紧张处反而拉长不切，和短视频常见的快切正相反；转场以硬切为主。
- **结尾**：满月下黑狗剪影定格收束。

## 可复用的规律

1. **写实 AI 短片的紧张感靠时长，不靠切速**。对峙镜头敢 hold 住，前提是眼神和呼吸感写进提示词。
2. **同框数量先锁死**。群像动物最容易多一只少一只，拆解和生成都按「同段内数量恒定」检查。
3. **体型差用机位解决**。仰拍给威胁方、平视给主角，比在提示词里写「更大」可靠。
4. **递进出场**：远 → 正面 → 贴身，三级景别是给威胁方出场的通用排法。

## 复刻提示词方向

对峙镜头提示词示例结构：侧面平视固定机位，两只动物鼻尖相对同框，浅景深，背景冷蓝夜色，火光从一侧打亮双方的脸，眼睛特写凝视，动作幅度极小。Avoid 清单：不要多余的动物、不要镜头推进、不要张嘴说话口型。
